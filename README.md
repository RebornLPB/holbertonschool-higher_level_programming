# Holberton School - Higher-Level Programming

## 📖 About
This repository gathers the projects completed during the **Higher-Level Programming** track at **Holberton School**, focused on writing more advanced, real-world Python code: reading and writing data in different serialization formats (JSON, Pickle, CSV, XML).

---

## 🛠️ General Requirements & Environment
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** All Python source files strictly comply with **PEP 8** (verified via `pycodestyle`).

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights |
| :--- | :--- |
| [`python-serialization`](python-serialization/) | JSON, Pickle, CSV, and XML serialization/deserialization |
