# Holberton School - Higher-Level Programming

## 📖 About
This repository gathers the projects completed during the **Higher-Level Programming** track at **Holberton School**, focused on real-world programming: Python serialization (JSON, Pickle, CSV, XML), consuming and building REST APIs, database access with an ORM, and an introduction to JavaScript (Node.js and DOM manipulation).

---

## 🛠️ General Requirements & Environment
* **OS:** Ubuntu 20.04 LTS
* **Python:** `python3` (version 3.8.5+)
* **JavaScript:** Node.js (`node`) for the warm-up scripts, a web browser for DOM manipulation
* **Database:** MySQL (for the ORM project)
* **Style Guide:** All Python source files are meant to follow **PEP 8** (check with `pycodestyle`).

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights |
| :--- | :--- |
| [`python-serialization`](python-serialization/) | JSON, Pickle, CSV, and XML serialization/deserialization |
| [`restful-api`](restful-api/) | `requests`, `http.server`, Flask, Basic Auth and JWT |
| [`python-object_relational_mapping`](python-object_relational_mapping/) | `MySQLdb`, SQL injection, SQLAlchemy models and sessions |
| [`javascript-warm_up`](javascript-warm_up/) | Node.js basics: arguments, loops, functions, objects, modules |
| [`javascript-dom_manipulation`](javascript-dom_manipulation/) | DOM selection, events, `fetch` and remote APIs |
